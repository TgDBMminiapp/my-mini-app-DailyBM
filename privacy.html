Политика конфиденциальности

Как DailyBookimix обращается с вашим дневником, заметками, привычками, задачами и воспоминаниями.

Last updated: 7 September 2026

1Who we are

DailyBookimix is a Telegram Mini App that lets you keep a private diary, notes, habits, daily tasks and memories.

The developer does not collect, receive, store or process any of your personal content on any own servers. No user data is sold, shared with advertisers or third parties for marketing. Privacy and security of your data are the core priority of this app.

2Data we process

  • Telegram profile data (user ID, first/last name, profile photo) — received only via Telegram's official WebApp API and used solely to display your name and avatar inside the app. This data is never sent to the developer.
  • Your content (notes, habits, tasks, memories, nickname, streaks, achievements) — created and stored by you.
  • Technical data — standard web hosting logs (e.g. IP address, browser type) that may be generated by the hosting provider (Vercel) when the static files of the app are loaded. The developer does not access or analyse these logs for user identification.

We do not use analytics, tracking pixels, advertising SDKs or any other tools that collect behavioural data.

3How your data is protected (encryption)

All your content is encrypted on your device before it is saved:

  • A random 256-bit Master Key is generated once using the Web Crypto API (crypto.getRandomValues).
  • Your data is encrypted with AES-256-GCM using this Master Key.
  • The Master Key itself is stored only locally (Telegram SecureStorage / DeviceStorage / localStorage) and never leaves your device in readable form.
  • A recovery code (shown once) protects a copy of the Master Key via PBKDF2 (600,000 iterations, SHA-256) + AES.
  • Only encrypted blobs are written to Telegram CloudStorage (for cross-device sync under your Telegram account). The developer has no access to the plaintext content or the Master Key.

4Where data is stored

  • Encrypted data → Telegram CloudStorage, DeviceStorage, SecureStorage and your device's localStorage.
  • Static app files → Vercel hosting.

Telegram and Vercel act as independent processors according to their own privacy policies. The developer does not control their infrastructure.

5Your rights

You can delete all your data at any time via the "Delete account & all data" button in the sidebar. After deletion the encrypted data is removed from the storages used by the app.

You may also stop using the app and delete the chat with the bot.

6Changes

We may update this Policy. The current version is always available on this page and via the bot settings.

7Contact

For any privacy-related questions please contact the developer through the Telegram bot linked to DailyBookimix.

By using the app you acknowledge this Privacy Policy.

1Кто мы

DailyBookimix — это мини-приложение Telegram, которое позволяет вести личный дневник, заметки, привычки, ежедневные задачи и воспоминания.

Разработчик не собирает, не получает, не хранит и не обрабатывает какой-либо ваш личный контент на собственных серверах. Никакие пользовательские данные не продаются и не передаются рекламодателям или третьим лицам в маркетинговых целях. Конфиденциальность и безопасность ваших данных — главный приоритет этого приложения.

2Какие данные мы обрабатываем

  • Данные профиля Telegram (ID пользователя, имя/фамилия, фото профиля) — получаются только через официальный WebApp API Telegram и используются исключительно для отображения вашего имени и аватара внутри приложения. Эти данные никогда не передаются разработчику.
  • Ваш контент (заметки, привычки, задачи, воспоминания, никнейм, стрики, достижения) — создаётся и хранится вами.
  • Технические данные — стандартные логи веб-хостинга (например, IP-адрес, тип браузера), которые могут создаваться хостинг-провайдером (Vercel) при загрузке статических файлов приложения. Разработчик не получает доступ к этим логам и не анализирует их для идентификации пользователей.

Мы не используем аналитику, трекинг-пиксели, рекламные SDK или любые другие инструменты, собирающие поведенческие данные.

3Как защищены ваши данные (шифрование)

Весь ваш контент шифруется на вашем устройстве перед сохранением:

  • Случайный 256-битный Мастер-ключ генерируется один раз с помощью Web Crypto API (crypto.getRandomValues).
  • Ваши данные шифруются алгоритмом AES-256-GCM с использованием этого Мастер-ключа.
  • Сам Мастер-ключ хранится только локально (Telegram SecureStorage / DeviceStorage / localStorage) и никогда не покидает ваше устройство в открытом виде.
  • Код восстановления (показывается один раз) защищает копию Мастер-ключа с помощью PBKDF2 (600 000 итераций, SHA-256) + AES.
  • В Telegram CloudStorage записываются только зашифрованные блоки данных (для синхронизации между устройствами в рамках вашего аккаунта Telegram). У разработчика нет доступа ни к незашифрованному контенту, ни к Мастер-ключу.

4Где хранятся данные

  • Зашифрованные данные → Telegram CloudStorage, DeviceStorage, SecureStorage и localStorage вашего устройства.
  • Статические файлы приложения → хостинг Vercel.

Telegram и Vercel действуют как независимые обработчики данных в соответствии со своими собственными политиками конфиденциальности. Разработчик не контролирует их инфраструктуру.

5Ваши права

Вы можете удалить все свои данные в любой момент с помощью кнопки «Удалить аккаунт и все данные» в боковом меню. После удаления зашифрованные данные удаляются из всех хранилищ, используемых приложением.

Вы также можете прекратить использование приложения и удалить чат с ботом.
